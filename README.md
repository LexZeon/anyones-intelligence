# Anyone's Intelligence

**English** | [简体中文](README.zh-CN.md)

Anyone's Intelligence is my project for learning about artificial intelligence and exploring simulated cognition in language models. Drawing inspiration from the philosophy of language, linguistics, and Lacanian psychoanalysis, I want to develop my own theory and use its proposed cognitive chain as a reference for model prototypes.

Quantification is central to this work: I hope to translate changes in state, memory connections, and their joint effects into quantifiable, executable model mechanisms. Long-term aims include reliable understanding, eliminating hallucinations and black-box opacity, deeper understanding of art, culture, and politics, innovative problem-solving, and exploring the possibility of consciousness.

**Current status:** research documentation and conceptual diagrams; no model implementation or experimental results yet. Offline operation and restrictions on networking and local agent capabilities are design requirements; isolation controls still need implementation and verification.
