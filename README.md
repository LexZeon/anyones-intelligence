# Anyone's Intelligence

Anyone's Intelligence 是一个研究与原型项目，探索由现代语言哲学、语言学和拉康精神分析启发的新型语言模型。项目希望从语言表示、学习目标和推理机制入手，提高模型理解语境、识别自身知识边界、解释判断和提出新解法的能力。

长期愿景包括消除 AI 幻觉、消除黑箱、提高使用安全性，以及探索与“意识”有关的问题，并深化模型对艺术、文化与政治的理解。这些愿景需要分阶段检验；目前不作为已实现能力或可保证的结果。

## 研究方向

| 方向 | 首先检验的能力 |
| --- | --- |
| 理解语言 | 识别歧义、指代和说话者立场，在语境变化后修订解释，完成未见过的组合与反事实任务。 |
| 控制幻觉 | 区分有依据的事实、推断和未知，在相同回答覆盖率下减少错误断言。 |
| 提高可解释性 | 找到实际影响输出的内部状态，并通过删除、替换和干预验证其作用。 |
| 艺术文化政治理解 | 区分事实、解释与价值判断，提出有材料依据的多种解读，并回应反证。 |
| 自主思考与创新 | 在固定计算预算内提出候选方案、检查结果并修订；用未见问题的可验证结果评价。 |
| 意识研究 | 研究自我模型、元认知等可操作的机制；把它们与主观体验是否存在的问题分别讨论。 |

项目以模型机制创新为研究对象。现有模型可以用于对照或早期验证，最终架构保持开放；给现有模型增加提示词、检索或反思流程的结果，需要与模型本体创新分别报告。

## 哲学与实验的关系

拉康精神分析已由项目发起人确认为思想来源。后续应选定原文与版本，记录概念的语境，再提出工程假设。每项假设都要明确表示方式、训练方法、对照实验和失败条件。

哲学概念为研究提供问题和结构启发；模型实验检验某种工程机制是否有效。两者之间的对应关系本身也需要论证，不能直接把 token、向量或某个模块命名为一个哲学概念，就视为完成了实现。

## 首个原型

建议先建立一个可以离线训练、检查内部状态的小规模语言实验：

1. 使用可控的本地文本与合成世界，覆盖证据充分、证据不足、前提错误和证据冲突四类问题。
2. 建立小型语言模型基线，比较加入语境关系表示、证据关联和不确定性机制后的结果。
3. 对候选内部状态做干预，检验模型是否实际依赖这些状态作答。
4. 同时报告准确性、回答覆盖率、错误风险、泛化能力和计算成本。

首轮只验证少量机制，不以训练通用大模型或证明意识为验收目标。合成任务上的改进还需要在自然语言材料上独立复验。

## 开发阶段的安全边界

原型默认采用离线运行设计：不提供浏览器、Shell、桌面控制或外部工具调用；输入语料只读，输出限制在专用目录，并限制运行时间、内存和迭代次数。模型生成的文本一律作为数据处理，不执行其中的指令或代码。

进程出网和文件访问限制必须由运行环境实施并测试。文档约定、提示词和“本地运行”本身不能证明隔离已经生效。
