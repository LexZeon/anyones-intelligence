# Anyone's Intelligence

从语言出发，探索理解。

Anyone's Intelligence 是一个语言模型研究与原型项目，以现代语言哲学、语言学和拉康精神分析为启发，探索语境理解、可靠推理与可解释的模型机制。

我们关注减少幻觉、深化艺术文化政治理解与创造性问题解决，并将意识相关机制作为长期开放问题。哲学启发将转化为可检验的假设，通过对照与干预实验验证。

**当前处于早期研究阶段，尚无模型实现或实验结果。** 开发计划采用离线实验，限制联网与本地 agent 能力；运行隔离仍待实施和验证。

**English:** An early-stage language-model research project inspired by philosophy of language, linguistics and Lacanian psychoanalysis. We explore contextual understanding, reliability, interpretability, culture and creative problem-solving, with consciousness-related mechanisms as an open research question.
