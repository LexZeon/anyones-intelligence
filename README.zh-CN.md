# Anyone's Intelligence

[English](README.md) | **简体中文**

Anyone's Intelligence 是我学习人工智能、探索语言模型中模拟认知的项目。我希望从语言哲学、语言学和拉康精神分析获得启发，发展自己的理论，并参考我提出的认知链构建模型原型。

量化是这项研究的核心：我希望将状态变化、记忆联系及其共同作用，转化为可量化、可运行的模型机制。长期目标包括可靠的理解、消除幻觉与黑箱、深入理解艺术文化政治、创新解题，以及探索意识产生的可能。

**当前完成的是研究文档与概念图，尚无模型实现或实验结果。** 默认离线运行、限制联网和本地 agent 能力是开发要求，具体隔离措施仍待实施与验证。
