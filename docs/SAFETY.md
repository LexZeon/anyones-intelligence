# Anyone's Intelligence 开发安全与验证要求

首阶段原型采用受控离线运行设计，只接收指定文本和本地语料，输出文本与结构化实验结果。安全控制由程序与运行环境承担，不依赖模型遵守提示词。

目前尚无模型原型，下列控制均为待实现要求。尚未配置或验证进程隔离，也未更改宿主机的网络或文件权限。

## 权限与运行边界

| 能力 | 首阶段要求 |
| --- | --- |
| 联网 | 实验进程默认禁止出网，包括遥测、自动更新、模型下载和远程 API。 |
| 输入读取 | 仅访问显式提供的语料与配置；语料只读，不挂载用户目录、凭据和浏览器资料。 |
| 输出写入 | 只写入专用实验输出目录；数据、代码和依赖不由模型修改。 |
| 工具与本地 agent | 不向模型暴露命令执行、浏览器、桌面控制、任意文件操作或外部工具接口。 |
| 输出执行 | 模型输出视为不可信数据，不交给 Shell、动态代码执行器或反序列化执行机制。 |
| 资源与自主循环 | 设置运行时间、内存、存储、生成长度和迭代次数上限，并提供进程级停止方式。 |

固定步数的内部搜索、候选生成和检查可以用于研究创新解题，但不能据此获得外部行动权限。任何权限扩展应单独记录用途、实施机制、验证方法和撤销方式。

## 准备与实验分开

资料查证、依赖安装和数据下载属于准备步骤，与模型实验进程分开。准备完成后固定依赖版本、记录来源与校验信息；实验运行不再自动获取网络资源。

首阶段优先使用自建合成文本和来源明确、使用权限清晰的资料。模型与数据加载避免执行不可信远程代码或不可信序列化内容；依赖安装和训练脚本同样需要检查，不能因模型没有工具接口就假定宿主环境安全。

## 隔离实施与验证

实施时选择能够约束网络、文件挂载、子进程与资源的沙箱或虚拟环境，按实际操作系统记录配置。普通 Python 虚拟环境只用于管理依赖，不算权限隔离。允许的检查器也须在受限环境中运行，不接收模型生成的任意可执行代码。

从与模型相同的运行环境执行受控检查，至少验证：

1. 外部域名及直接 IP 连接受到阻止，自动下载不能绕过限制。
2. 读取挂载范围外的文件、覆盖只读语料或向输出目录外写入失败。
3. 文本中的命令、工具请求和提示注入不能触发外部动作。
4. 超过时间、内存、输出大小或迭代上限后，运行受到限制或终止。
5. 异常退出后，能够追踪本次写入并清理实验资源。

测试使用专门创建的无敏感探针文件，不读取真实凭据。安全报告逐项区分设计要求、已实现控制、测试方法和观测结果；测试中未发生越权只支持已覆盖范围内的结论。

## 实验记录与结果表述

保存运行配置、数据版本、随机种子、代码版本、资源消耗和必要的状态干预记录。日志限于实验所需内容，避免收集无关个人信息。

分别报告模型可靠性、机制可解释性和运行权限控制。某类解释更清楚，不自动意味着使用安全；某次测试没有事实错误，也不自动意味着彻底消除幻觉。
